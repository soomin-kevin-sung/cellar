# cellar
A self-hosted hub for securely managing a PC remotely

## Web preview

The first Cellar product shell is available in `web/`. It currently uses representative demo data while the remaining file-mutation APIs are completed.

```powershell
npm --prefix web install
npm --prefix web run dev
```

The development server listens on port `4173`. Run `npm --prefix web run build` to create the production bundle.
